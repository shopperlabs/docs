Payment methods represent the ways customers can pay for their orders. Shopper provides a flexible system to manage multiple payment providers, each with its own driver, description, and customer-facing instructions.

## Model

The model used is `Shopper\Core\Models\PaymentMethod`. It implements `Shopper\Core\Models\Contracts\PaymentMethod` and uses the `HasSlug` and `HasZones` traits. The model is not configurable via `config/shopper/models.php`.

## Database Schema

### PaymentMethod Table

| Column | Type | Nullable | Default | Description |
|--------|------|----------|---------|-------------|
| `id` | bigint | no | auto | Primary key |
| `title` | string | no | - | Payment method name |
| `slug` | string | yes | null | URL-friendly identifier (unique) |
| `logo` | string | yes | null | Not read by Shopper: the logo comes from the driver, see [Logo Handling](/2.x/payment-methods#logo-handling) |
| `link_url` | string | yes | null | Payment provider website or documentation URL |
| `description` | text | yes | null | Description displayed to customers when choosing a payment method |
| `instructions` | text | yes | null | Instructions displayed to customers after placing an order |
| `is_enabled` | boolean | no | false | Whether the method is active. Methods added in the admin start disabled |
| `driver` | string | yes | null | Payment driver code (`manual`, `stripe` or a custom driver), added by `shopper/payment`. `null` is handled as `manual` |
| `metadata` | jsonb | yes | null | Custom data. The model does not cast it, so it reads back as a JSON string |
| `created_at` | timestamp | yes | null | Creation timestamp |
| `updated_at` | timestamp | yes | null | Last update timestamp |

The admin fills `slug` from the title. In code, the slug is not generated: pass it yourself. The `HasSlug` trait turns the value into a slug and appends `-1`, `-2` when it is already taken.

## Contract

The `PaymentMethod` contract defines the interface that all payment method models must implement:

```php
namespace Shopper\Core\Models\Contracts;

use Illuminate\Database\Eloquent\Relations\MorphToMany;

interface PaymentMethod
{
    public function zones(): MorphToMany;
}
```

Payment methods use zones to control availability by geographic region. A payment method can be assigned to multiple zones, and a zone can have multiple payment methods.

<Note>
The `driver` column connects a payment method to a registered payment driver. `manual` is built in, `stripe` comes with the `shopper/stripe` package, and you add others with `Payment::extend()`. A `null` driver resolves to `manual`, and a code that no driver is registered under makes `Payment::driver()` throw an `InvalidArgumentException`. When the `PaymentProcessingService` processes a payment, it uses this value to resolve the correct driver. See [Payments](/2.x/payments) for driver registration and the full payment lifecycle.
</Note>

## Relationships

### Zones

Payment methods can be scoped to specific geographic zones using the `HasZones` trait:

```php
$paymentMethod->zones;
$paymentMethod->zones()->attach([$zoneId1, $zoneId2]);
$paymentMethod->zones()->detach($zoneId);
```

In the admin, payment methods are assigned to a zone from the zone form. From the zone side, use `$zone->paymentMethods` (see [Zones](/2.x/zones#payment-methods)).

### Orders

Orders reference payment methods via the `payment_method_id` foreign key:

```php
$order->paymentMethod;
```

```php
Order::query()
    ->where('payment_method_id', $paymentMethod->id)
    ->get();
```

The foreign key is nullable: deleting a payment method keeps its orders and sets their `payment_method_id` to `null`.

## Query Scopes

```php
PaymentMethod::query()->enabled()->get();
```

## Logo Handling

A payment method shows the logo of its driver. The `logo()` method returns the URL the driver provides (the `manual` and `stripe` drivers ship one), or `null` when the driver has none or `shopper/payment` is not installed. `PaymentProcessingService::getLogoUrl()` returns the same value:

```php
use Shopper\Payment\Services\PaymentProcessingService;

$paymentMethod->logo(); // Driver logo URL or null

$service = resolve(PaymentProcessingService::class);
$service->getLogoUrl($paymentMethod); // Same as $paymentMethod->logo()
```

The `logo` column is neither filled by the admin nor read by `logo()`. To show a logo for your own driver, return its URL from the driver's `logo()` method (see [Custom Drivers](/2.x/payments#custom-drivers)).

## Creating Payment Methods

### Basic Payment Method

The `stripe` driver needs the `shopper/stripe` package (see [Available Drivers](/2.x/payments#available-drivers)). Leave out `is_enabled` and the method is created disabled.

```php
use Shopper\Core\Models\PaymentMethod;

$paymentMethod = PaymentMethod::query()->create([
    'title' => 'Credit Card',
    'slug' => 'credit-card',
    'driver' => 'stripe',
    'link_url' => 'https://stripe.com',
    'description' => 'Pay securely with your credit or debit card.',
    'instructions' => 'Your card will be charged immediately upon order confirmation.',
    'is_enabled' => true,
]);
```

### Cash on Delivery

```php
$cod = PaymentMethod::query()->create([
    'title' => 'Cash on Delivery',
    'slug' => 'cash-on-delivery',
    'driver' => 'manual',
    'description' => 'Pay with cash when your order is delivered.',
    'instructions' => 'Please have the exact amount ready for the delivery driver.',
    'is_enabled' => true,
]);
```

### Bank Transfer

```php
$bankTransfer = PaymentMethod::query()->create([
    'title' => 'Bank Transfer',
    'slug' => 'bank-transfer',
    'driver' => 'manual',
    'description' => 'Pay via direct bank transfer.',
    'instructions' => 'Please transfer the total amount to the following account: IBAN XX00 0000 0000 0000. Use your order number as the payment reference.',
    'is_enabled' => true,
]);
```

### Zone-Scoped Payment Method

```php
$mobileMoney = PaymentMethod::query()->create([
    'title' => 'Mobile Money',
    'slug' => 'mobile-money',
    'link_url' => 'https://notchpay.co',
    'description' => 'Pay with your mobile money wallet.',
    'is_enabled' => true,
]);

$mobileMoney->zones()->attach([$africaZoneId]);
```

## Retrieving Payment Methods

```php
$methods = PaymentMethod::query()->enabled()->get();
```

Find by slug:

```php
$method = PaymentMethod::query()
    ->where('slug', 'credit-card')
    ->first();
```

`PaymentMethod::findBySlug('credit-card')` from the `HasSlug` trait does the same, but throws a `ModelNotFoundException` when no method matches.

Payment methods available in a specific zone:

```php
$methods = PaymentMethod::query()
    ->enabled()
    ->whereHas('zones', fn ($q) => $q->where('zone_id', $zoneId))
    ->get();
```

`PaymentProcessingService::getMethodsForZone()` returns the zone's enabled methods whose driver is configured. It only returns methods attached to the zone (see [Payments](/2.x/payments#getting-available-payment-methods-for-a-zone)):

```php
use Shopper\Payment\Services\PaymentProcessingService;

$methods = resolve(PaymentProcessingService::class)->getMethodsForZone($zone);
```

Payment methods with no zone restriction (available everywhere):

```php
$globalMethods = PaymentMethod::query()
    ->enabled()
    ->whereDoesntHave('zones')
    ->get();
```

## Working with Orders

When creating an order, associate it with the selected payment method:

```php
use Shopper\Core\Models\Order;

$order = Order::query()->create([
    'number' => $orderNumber,
    'customer_id' => $customerId,
    'payment_method_id' => $paymentMethod->id,
    // ... other order fields
]);

$order->paymentMethod->title;
$order->paymentMethod->instructions;
```

`CreateOrderFromCartAction` does not set `payment_method_id`. Set it on the order the action returns (see [Order Conversion](/2.x/cart#order-conversion)):

```php
$order->update(['payment_method_id' => $paymentMethod->id]);
```

## Storefront Example

### Checkout Payment Selection

```php
namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Shopper\Cart\Facades\Cart;
use Shopper\Core\Models\PaymentMethod;
use Shopper\Core\Models\Zone;

class CheckoutController extends Controller
{
    public function showPayment()
    {
        $zone = $this->getCustomerZone();

        $paymentMethods = PaymentMethod::query()
            ->enabled()
            ->where(function ($query) use ($zone): void {
                $query->whereHas('zones', fn ($q) => $q->where('zone_id', $zone?->id))
                    ->orWhereDoesntHave('zones');
            })
            ->get();

        return view('checkout.payment', compact('paymentMethods'));
    }

    public function storePayment(Request $request)
    {
        $paymentMethod = PaymentMethod::query()->enabled()->findOrFail(
            $request->input('payment_method_id')
        );

        session()->put('checkout.payment_method_id', $paymentMethod->id);

        return redirect()->route('checkout.review');
    }

    private function getCustomerZone(): ?Zone
    {
        $countryId = Cart::current()?->shippingAddress()?->country_id;

        if (! $countryId) {
            return null;
        }

        return Zone::query()
            ->enabled()
            ->whereHas('countries', fn ($q) => $q->where('id', $countryId))
            ->first();
    }
}
```

<Note>
In this example, payment methods without any zone are shown to all customers regardless of their location. `getMethodsForZone()` does not follow this rule: it only returns methods attached to the zone.
</Note>

## Use Cases

Any of these can be a payment method. A method that charges online needs a driver: Shopper ships `manual` and `stripe`, and you write [custom drivers](/2.x/payments#custom-drivers) for the others.

| Payment Method | Description |
|----------------|-------------|
| Credit Card | Online card payments via Stripe, PayPal, etc. |
| Bank Transfer | Direct bank wire transfer |
| Cash on Delivery | Payment at delivery time |
| Mobile Money | Mobile wallet payments (M-Pesa, Orange Money, etc.) |
| PayPal | PayPal account or guest checkout |
| Cryptocurrency | Bitcoin, Ethereum, etc. |

| Scenario | Implementation |
|----------|----------------|
| Single payment provider | Create one enabled payment method |
| Region-specific methods | Use zones to restrict availability |
| Offline payments | Use `instructions` field for post-order guidance |
| Gateway documentation | Use `link_url` to reference provider docs |
| Display at checkout | Query enabled methods filtered by customer zone |
