Shopper requires an existing Laravel 11.28+, 12 or 13 application. If you do not have one yet, create a new Laravel project first by following the [Laravel installation guide](https://laravel.com/docs/installation).

## Install the Package

Install `shopper/framework` via Composer:

```bash
composer require shopper/framework
```

<Note>
  If you have a cached config from a previous setup, run `php artisan config:clear` before installing.
</Note>

## Prepare Your User Model

Shopper relies on your `User` model having certain relationships and methods for authentication, permissions, and admin panel access. Add the `InteractsWithShopper` trait and implement the `ShopperUser` interface on your User model:

```php title="app/Models/User.php"
use Illuminate\Foundation\Auth\User as Authenticatable;
use Shopper\Models\Contracts\ShopperUser;
use Shopper\Traits\InteractsWithShopper;

class User extends Authenticatable implements ShopperUser
{
    use InteractsWithShopper;

    protected $hidden = [
        'password',
        'remember_token',
        'store_two_factor_secret',
        'store_two_factor_recovery_codes',
    ];
}
```

The `InteractsWithShopper` trait provides roles and permissions, orders, addresses, discounts and the profile photo. Two-factor authentication needs two more contracts and traits, described on the [Two-Factor Authentication](/2.x/two-factor) page. The `ShopperUser` interface ensures your model adheres to the contract expected by Shopper's admin panel.

## Run the Installer

The install command publishes configuration files, creates the asset symlink, and optionally runs migrations and seeders:

```bash
php artisan shopper:install
```

The installer performs these steps:

1. Publishes Shopper config files to `config/shopper/`
2. Publishes Spatie MediaLibrary migrations
3. Publishes Filament assets
4. Creates a symlink from `vendor/shopper/framework/public` to `public/cpanel` (or your configured prefix)
5. Prompts you to run migrations and seed the database with roles, permissions, and default data

If `config/shopper/admin.php` already exists, the installer stops and prints the commands to publish the configuration and run the migrations by hand.

<Warning>
  The migrations change your `users` table: the `name` column is renamed to `last_name`, and columns such as `first_name`, `gender`, `phone_number` and `birth_date` are added. Update any code, factory or form of your application that reads or writes `name` before you migrate.
</Warning>

<Note>
  All Shopper database tables are prefixed with `sh_` by default to avoid conflicts with your existing tables. To use another prefix, answer no when the installer asks to run the migrations, change `table_prefix` in `config/shopper/core.php`, then run `php artisan migrate` and the two seeders listed on the [Configuration](/2.x/configuration#database-table-prefix) page.
</Note>

Product, category and brand images are stored on the `public` disk. If your application has never run it, create the storage link so that they are served:

```bash
php artisan storage:link
```

## Create an Admin User

Create your first admin user to access the dashboard:

```bash
php artisan shopper:user
```

The command prompts for an email, first name, last name, and password (at least 6 characters). The user is assigned the administrator role, which exists only once the seeders have run: if you skipped them in the installer, run them first.

## Access the Admin Panel

If you are using [Laravel Herd](https://herd.laravel.com) or [Laravel Valet](https://laravel.com/docs/valet), visit your application at:

```
http://your-project.test/cpanel/login
```

If you are using `php artisan serve`, the admin panel is available at `http://localhost:8000/cpanel/login`.

On the first login, Shopper redirects you to a setup wizard that asks for the store name, email, address and currencies. The admin panel opens once these are saved. See [Setup Store](/2.x/setup-store) for what the wizard creates.

The `/cpanel` prefix is configurable. See the [Configuration](/2.x/configuration) page for details.
