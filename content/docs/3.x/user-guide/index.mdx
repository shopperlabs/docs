The User Guide is for the people who run the store. Its groups follow the admin menu: Getting Started, Store Setup, Catalog, Sales, Marketing and Administration.

Until a screen is covered here, the [2.x User Guide](/2.x/user-guide/getting-started/introduction) describes the screens that already existed in 2.x.
