The User Guide is for the people who run the store: owners, managers and staff who add products, handle orders and answer customers from the admin panel. Each page covers one screen, shows it in a screenshot and walks through its tasks step by step. No page asks you to write code.

The groups follow the admin sidebar: Getting Started, Catalog, Sales, Customers and Settings.

<Cards>
  <Card title="Getting Started" icon="rocket" href="/3.x/user-guide/getting-started/introduction">
    Log in, read the dashboard, finish the setup guide, follow your notifications and protect your account with two-factor authentication.
  </Card>
  <Card title="Catalog" icon="package" href="/3.x/user-guide/catalog/products/overview">
    Create products and their variants or import them from a CSV file, set their prices, and organize them with brands, categories, collections, attributes, tags and suppliers.
  </Card>
  <Card title="Sales" icon="shopping-cart" href="/3.x/user-guide/sales/orders">
    Follow each order from payment to delivery, track shipments, refund payments, review abandoned carts, and run promotions with discount codes and campaigns.
  </Card>
  <Card title="Customers" icon="users" href="/3.x/user-guide/sales/customers">
    Look up customer profiles, addresses and orders, and moderate product reviews.
  </Card>
  <Card title="Settings" icon="settings" href="/3.x/user-guide/store-setup/general-settings">
    Set up the store, its look, locations, sales channels, currencies, zones, carriers, payment methods, taxes, legal pages and webhooks, and decide what each staff member can do.
  </Card>
</Cards>

<Tip>
  Developers who install, configure or extend Shopper start with the [Documentation](/3.x/getting-started) tab.
</Tip>
