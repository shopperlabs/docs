Storefront covers the customer side of a Shopper store: the starter kits, the Store API that serves products, carts, checkout, customers and orders as JSON:API, and the JavaScript SDK that wraps it.

The [Store API](/3.x/store-api) guides cover every endpoint a storefront calls, from the catalog to the order history. The starter kit and SDK pages are being written during the 3.0 release candidate.
