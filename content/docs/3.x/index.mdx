Shopper 3 is in release candidate. This version of the documentation is being written page by page.

Until a topic is covered here, the [2.x documentation](/2.x/getting-started) describes how the admin panel and the core models work. The concepts are the same; the upgrade guide will list what changed between 2.x and 3.x.

## Requirements

- PHP 8.3 or higher
- Laravel 12 or 13
