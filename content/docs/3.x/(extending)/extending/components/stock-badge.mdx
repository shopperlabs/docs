The stock badge shows a stock quantity in a small rounded badge, colored by level. The products table uses it in its stock column.

## Preview

The preview shows a low quantity and two normal ones.

<ComponentPreview>
  <div style={{ display: 'flex', gap: 16, alignItems: 'center' }}>
    <PreviewStockBadge stock={5} />
    <PreviewStockBadge stock={25} />
    <PreviewStockBadge stock={100} />
  </div>
</ComponentPreview>

## Usage

Pass the quantity to the `stock` prop:

```blade
<x-shopper::stock-badge :stock="$product->stock" />
```

## Props

The badge takes a single prop and no slot. It ignores other attributes.

<ApiTable name="x-shopper::stock-badge" element="span">

<ParamField path="stock" type="int" required>
  The quantity to display.
</ParamField>

</ApiTable>

## Behavior

The color depends on the quantity. The threshold of 10 units is fixed in the view: to change it, [override the view](/3.x/extending/components/overview#customization).

| Stock value | Color | Meaning |
|------------|-------|---------|
| `< 10` | Red (`danger`) | Low stock |
| `>= 10` | Green (`success`) | Stock OK |

## Examples

The examples below show both colors and the badge in a table column.

### Low Stock

A quantity under 10 renders red.

<ComponentPreview>
  <PreviewStockBadge stock={3} />
</ComponentPreview>

```blade
<x-shopper::stock-badge :stock="3" />
```

### Normal Stock

A quantity of 10 or more renders green.

<ComponentPreview>
  <PreviewStockBadge stock={50} />
</ComponentPreview>

```blade
<x-shopper::stock-badge :stock="50" />
```

### In a Table

In a Filament table, render the badge from a `ViewColumn`. The view receives the row through `$getRecord()`:

```php
use Filament\Tables\Columns\ViewColumn;

ViewColumn::make('stock')
    ->label('Stock')
    ->view('livewire.tables.cells.stock')
```

```blade title="resources/views/livewire/tables/cells/stock.blade.php"
@php
    $product = $getRecord();
@endphp

<div class="flex items-center">
    <x-shopper::stock-badge :stock="$product->stock" />
    <span class="text-sh-fg-secondary text-sm/6">in stock</span>
</div>
```

Shopper's products table renders its stock column the same way, with the view `shopper::livewire.tables.cells.products.stock`.

## Blade Component Source

The view is `resources/views/components/stock-badge.blade.php` in the `shopper/framework` package:

```blade
@blaze(memo: true)

@props([
    'stock',
])

<span
    @class([
        'me-2 inline-flex rounded-full px-1.5 text-xs leading-5 font-semibold',
        'bg-danger-100 text-danger-800' => $stock < 10,
        'bg-success-100 text-success-800' => $stock >= 10,
    ])
>
    {{ $stock }}
</span>
```
