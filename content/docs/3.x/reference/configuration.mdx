This page lists every key of the Shopper configuration files, with its default value and the environment variable that sets it. `php artisan shopper:install` publishes the main files to `config/shopper`, and `php artisan vendor:publish --tag=shopper-config` publishes them again; the files with their own command are listed in [Files](#files).

## Files [#files]

Each Composer package merges its files under the key below, so a file you do not publish keeps the package defaults. The last column is the option of `php artisan vendor:publish` that copies the file into your application.

## shopper.addons [#shopper-addons]

`config/shopper/addons.php` turns installed add-ons off. It ships empty, so every installed add-on is active.

| Key | Default | Env | Description |
|-----|---------|-----|-------------|
| `shopper.addons.{id}` | `true` | | `false` disables the add-on with this ID, see [Disabling an Add-on](/3.x/addons#disabling-an-addon) |
